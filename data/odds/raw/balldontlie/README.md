# BALLDONTLIE Raw Odds

Generated by:

```bash
python3 warehouse/fetch_balldontlie_odds.py --line-types opening --request-interval-seconds 13
```

The adapter writes:

- `data/odds/raw/balldontlie/events_*.json`
- `data/odds/raw/balldontlie/odds_opening_event_*.json`
- `data/odds/sources/balldontlie_fight_odds.csv`
- `data/odds/sources/balldontlie_unmatched_odds.csv`
- `data/reports/balldontlie_odds_matching_qa.csv`

The current-odds endpoint returned no rows for the completed prediction-window
events tested on 2026-08-19, so opening odds are the useful BALLDONTLIE feed for
the current historical backtest data pull.
