# SportsDataIO Raw Odds

Generated by:

```bash
python3 warehouse/fetch_sportsdataio_odds.py --event-id-start 891 --event-id-end 920
```

The adapter writes:

- `data/odds/raw/sportsdataio/event_odds_*.json`
- `data/odds/raw/sportsdataio/event_odds_line_movement_*.json`
- `data/odds/sources/sportsdataio_fight_odds.csv`
- `data/odds/sources/sportsdataio_unmatched_odds.csv`
- `data/reports/sportsdataio_odds_matching_qa.csv`

Important: the current API key appears to return SportsDataIO trial/dev data.
SportsDataIO marks MMA fight moneyline fields as scrambled for trial/dev access,
so these odds should be used for adapter and pipeline testing only until a real
licensed odds key is available.
